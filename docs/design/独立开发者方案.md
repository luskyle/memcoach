# 记忆教练：独立开发者方案（工具版）

> 按《实用化转型》重做：一人全职、10 周到公测、第一年 1.2~4 万现金即可启动的记忆工具。

## 一、为什么工具路线适合单人

| 单人最怕的坑 | 游戏版 | 记忆教练工具版 |
| --- | --- | --- |
| 美术/动画做不好 | 致命（宫殿=颜值） | **不存在**（设计=极简排版） |
| 内容产能跟不上 | 致命（玩法要内容喂） | **不存在**（Anki 兼容 + AI 成卡） |
| 留不住用户 | 靠新鲜感（无限内容） | 靠习惯（SRS 每日任务，产出可预测） |
| 与巨头竞争 | 拼资源 | **拼专注**：巨头看不上小工具的颗粒度 |

> 工具的成功公式与游戏相反：**功能越少、越克制，越成功**。一个人恰好能守住"少而精"。

## 二、产品范围：一处做深，处处做薄

### 2.1 做深（核心竞争力，投入 80%）

```
收藏管道 → 成卡 → SRS 复习 → 数据证明
四个入口：分享面板 / 剪贴板 / 拍照OCR / 手录
复习交互：先猜后看 + 三键评级 + 遗忘曲线
记忆库：搜索 / 筛选 / 分组 / Anki 导入导出
```

### 2.2 做薄（首版不做，明确留给后置）

| 不做 | 原因 | 归到 |
| --- | --- | --- |
| 社交/社区 | 单人维护不起 | V2 后 |
| 知识市场/UGC | 审核与质量成本 | V3 预研 |
| 多语言频道（英/韩） | 核心未验证前不摊饼 | V1.1（W11+） |
| 桌面端 | 移动端模型验证后复用代码 | V2（W25+） |
| 插件/API | 等有用户再开 | V2 |

### 2.3 MVP 功能清单（W1~6 交付）

```
[必须] 三 Tab 框架 · 收藏入口（分享面板+粘贴）· AI 成卡（可编辑）
      · SM-2 复习三键 · 遗忘曲线 · 记忆库搜索筛选 · 埋点 10 事件
[可以没有] OCR、剪藏正文、多语言、Anki 导入、云同步、桌面端
```

## 三、技术栈（单人可维护）

| 决策点 | 选择 | 原因 |
| --- | --- | --- |
| 客户端 | **Flutter**（移动 + 未来桌面免费复用） | 一套代码多端（技术调研 §3） |
| 状态/存储 | Riverpod + drift(SQLite) + Hive 缓存 | 类型安全、离线优先（§4） |
| SRS 引擎 | 自写 SM-2 纯函数（<100 行）→ FSRS | 可单测、可整体替换（§2） |
| AI | TTS 离线预生成 + 通义/DeepSeek 档批量成卡 | 一次性成本、零运行时大头（§6/7） |
| 后端 | 无（纯本地）→ Supabase/轻量服务器 | 存储 A→B→C 档逐步加（存储方案） |
| 分享面板/OCR | 平台通道 + 系统 OCR/mlkit | 全平台入口，几乎零成本 |
| 图表 | fl_chart（免费） | 遗忘曲线/热力图 |

> 全部依赖免费/开源，无一项需要预付款大额工具。

## 四、排期（全职 10 周到公测）

| 周 | 交付 | 里程碑 |
| --- | --- | --- |
| W1~2 | 工程 + SM-2 引擎单测 + 词库管线 + 三 Tab 骨架 | M0 可编译 |
| W3~4 | 收藏入口（分享/粘贴）+ AI 成卡（离线词库兜底）| 可收藏成卡 |
| W5~6 | 复习三键闭环 + 遗忘曲线 + 记忆库 | **M1 内测版（50 人）** |
| W7~8 | 打磨：反馈修复前 10 项 + 订阅墙 + 埋点排查 | 内测指标复盘 |
| W9~10 | 上架物料 + 内容营销启动 + 500 邀请码 | **M2 公测上架** |
| W11~16 | V1.1：OCR/剪藏正文/Anki 导入导出/月度报告 | M3 |
| W17~24 | V1.2：三层分类 + AI 打标 + WebDAV/iCloud + 热力图海报 | M4 |
| W25~36 | V2：桌面端 + FSRS + 云同步 C 档 | M5 |

**兼职（20h/周）**：全程 ×1.6 ≈ 16 周到公测；**2 人合伙**（开发 + 内容/运营）周期 ×0.7。

## 六、获客：工具赛道不买量

| 渠道 | 动作 | 预期 |
| --- | --- | --- |
| **商店 ASO** | 关键词：闪卡/记忆/背单词/收藏 | 中长期自然量主力 |
| **Reddit/知乎/HN** | 长文"我做了个 Readwise 中文版记忆工具" | 100~1000 级种子 |
| **开发者社区** | 开源 SRS 细节分享 / 独立开发日志 | 认同 + 口碑 |
| **B站/小红书** | 学习干货 + 用法演示（SRS 科普自带传播性） | 兴趣人群引流 |
| **老带新** | 分享"记忆资产统计卡"海报 + 邀请码 | 裂变 |
| **学校/教师（后期）** | 布置复习包（B 端微探索） | 团购订阅 |

> 工具冷启动比游戏慢，但**每一个自然用户都是"精准用户"**；Readwise 前两年也是口碑慢慢滚起来的——预期管理：第 3 个月 1000 下载是健康起点。

## 七、变现设计

| 档位 | 价格 | 说明 |
| --- | --- | --- |
| 免费额度 | 日 30 卡 + 100 卡库 | 体验 SRS 神奇曲线（3 天可见效果） |
| Pro 订阅 | 25 元/月 · 198 元/年 | 无限卡/AI 成卡/云同步/多语言 |
| 买断（可选） | 398 元终身 | 工具用户的买断情结 |
| 出海版 | $4.99/月 · $29.99/年 | 二次扩张（Memobox） |

- 付费墙时机：第 3 天（用户已见到第一条下降曲线），文案走数据而非焦虑。
- 工具属性 → 复购率高、口碑好；不做砍卡量的恐吓式付费。

## 八、风险与应对

| 风险 | 概率 | 应对 |
| --- | --- | --- |
| 工具功能太像 Anki/墨墨无人换 | 中 | Anki 兼容（无锁定）+ 收藏管道（差异化内核）+ 现代 UX |
| 冷启动慢（前 3 个月没人） | 高 | 预期管理 + 口碑内容持续 6 个月再看 |
| AI 成卡质量差拖口碑 | 中 | 离线词库兜底 + 全部可编辑 + 抽检规则 |
| 收藏即囤积（用户只存不学） | 中 | 防囤积机制（见收藏管道设计 §6） |
| 时间被多线拖垮 | 高 | 一处做深；W 计划固定调整窗口 |
| 功能边界膨胀 | 中 | 做薄清单常年挂在 README/跟进文档 |

## 九、里程碑与退出预期

| 里程碑 | 时间 | 指标 | 决策 |
| --- | --- | --- | --- |
| 内测 50 人 | W6 | 次留 > 35%、7 日 > 25% | 上架或重做核心交互 |
| 公测 1000 下载 | W14 | 付费率 > 1.5% | 持续迭代 or 调定价 |
| 5000 下载 | M6（约 W26） | 订阅 > 50 份/月 | 加桌面端/多语言 |
| 健康线 | 12 个月 | 订阅 300~1300/月收入 1 万 | 全职化或 B 端 |

**退出/转向预期**：
- 第 6 个月 DAU < 300 且无增长信号 → 转方向（换内容垂直：只做"考证记忆"等），损失仅 2~4 万与时间。
- 工具赛道的容错：**每个功能都是可迁移资产**（SRS 引擎/收藏管道/词库管线换赛道 100% 复用）。

> **一句话**：记忆教练的独立开发 = 3 个月全职 + 1.2~4 万现金，做一件"收藏进得来、复习跑得动、数据看得见"的小而准的工具——工具赛道不奖励炫技，只奖励"靠谱"。
