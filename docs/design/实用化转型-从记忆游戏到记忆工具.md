# 实用化转型：从「记忆游戏」到「记忆工具」

> **决策**：放弃游戏化外壳（宫殿/忆灵/蜡烛/远征/minigame），回归实用性记忆工具。
> **理由**：游戏化产品的美术、动效、内容产能、测试面，任何一环都是单人开发扛不住的大坑；而记忆科学引擎、收藏管道、分类、本地存储这些"真正的差异化"恰恰与游戏化无关——**砍掉外壳，内核依然是完整的产品。**

## 一、为什么必须转（诚实的成本账）

| 游戏化模块 | 单人成本（周） | 风险 |
| --- | --- | --- |
| 宫殿渲染/粒子动效 | 8~12 周 | 审美不过关 = 负分 |
| 吉祥物「忆灵」动画 | 4~6 周 + 外包 | 表情/动作是艺术活 |
| 家具卡面 × 300 | 外包 5~10 万 | 超出预算 |
| minigame × 3 | 6~10 周 | 做出来不好玩 = 白做 |
| 远征/Boss 剧情内容 | 持续产出 | 内容产能黑洞 |
| **工具化模块** | **单人成本** | |
| 收藏管道 + 复习引擎 | 4~6 周 | 逻辑确定、可测、可验证 |

> 结论：游戏化 = 把预算和时间压在"我没资源做好的地方"；工具化 = 把资源压在"我确定做得好的地方"（逻辑、数据、体验、克制的交互）。**承认边界本身就是产品决策。**

## 二、保留什么 / 砍掉什么 / 改什么

## 三、新产品定义

### 3.1 一句话定位

> **把你想记住的任何东西——单词、摘抄、灵感、考纲——划进一个"收件箱"，App 用间隔重复自动安排复习，直到你真正记住。**

### 3.2 Slogan 候选

- "收藏即记忆"
- "你划进来的东西，永远不会再被忘记"
- "From capture to memory"

### 3.3 对标原型（最强的参考系）

| 参考 | 证明的事 |
| --- | --- |
| **Readwise**（独立开发者/小团队） | "划线收藏 + 间隔复习"是能收 $99/年的产品；理念与我们要做的一模一样 |
| **Anki** | SRS 工具付费可行；短板=配置繁琐、UI 陈旧、手机端弱 |
| **墨墨背单词** | 中国人愿意为 SRS 付费；短板=只能背单词 |
| **Bear/Things**（独立工具） | 独立开发者做精致工具能长期活 | 

> **我们的位置**：Readwise 的收藏理念 × 墨墨的 SRS 口碑 × 现代极简 UI × 不做游戏的决心 = "中文世界的 Readwise + 记忆工具"。

## 四、信息架构：三个分区 + 一条管道

```
                     ┌─────────────────────────────┐
  输入管道（收藏）     │  ① 收件箱  ── 待整理/待学      │
  拍照 / 剪藏 / 粘贴  │  ② 复习队列 ── 今天该复习     │
  / 手动输入 / OCR    │  ③ 记忆库  ── 全部卡片（可筛） │
                     └─────────────────────────────┘
                     底部三 Tab 常驻，永远干净
```

- **Tab1 收件箱**：排序 = 收藏时间；卡片显示"是否已成卡/待归类"；一键"整理"（AI 打标建议）
- **Tab2 复习**：今日任务数、开始复习大按钮、曲线入口（工具核心页，占 UI 主角）
- **Tab3 记忆库**：搜索/筛选（语言、主题、来源、状态、已掌握）；支持文件夹视图与平铺视图
- 全局搜索：一字搜索所有卡片 + 记忆库（工具党的刚需）

## 五、核心交互设计（工具视角）

| 场景 | 交互 | 工具性细节 |
| --- | --- | --- |
| 收藏 | 分享面板（iOS/Android 全局"分享到本App"）+ 剪贴板监听 + 拍照 OCR | 从任何 App 任意 App 都能划进来 |
| 成卡 | AI 自动补释义/例句/发音（**克制：可一键全部编辑**） | 宁准确勿花哨；离线词库兜底 |
| 复习 | 闪卡先猜后看 + 三键评级（忘了/模糊/记得） | 键盘快捷键（桌面端）；批量标记 |
| 统计 | 遗忘曲线 + 复习热力图 + 薄弱分类 | 数据驱动个性化（薄弱自动加权） |
| 导入导出 | **Anki 牌组导入/导出**（双向）、CSV/JSON | 工具护城河：进出自如，无锁定 |
| 多设备 | 本地优先 + 用户云盘同步（存储方案 A/B/C 档） | 不登录也能用 |

## 六、差异化对比：我们 vs 四个邻居

| 维度 | Anki | 墨墨 | 笔记类(Notion/备忘录) | 我们 |
| --- | --- | --- | --- | --- |
| 上手成本 | 高（配置是门槛） | 中 | 高（自己搭体系） | **低：收藏即开始** |
| 内容范围 | 任意（但自己建） | 仅单词 | 任意（但不复习） | **任意 + 自动复习** |
| SRS 曲线 | 强（可调） | 强 | 无 | **强且傻瓜化** |
| 收藏体验 | 无 | 无 | 有但不复习 | **有且自动成卡** |
| 现代 UI | 差 | 朴素 | 好 | **好** |
| 数据进出自由 | 强 | 一般 | 强 | **强（Anki 兼容）** |

> 一句话差异：**"笔记收藏了我的知识，但没能让我记住；Anki 让我记住，但先要忍受配置。我们把两件事放进同一条管道。"**

## 七、UX 设计原则：克制的力量

1. **三 Tab 常驻**：结构永远不变，肌肉记忆；不做隐藏入口。
2. **复习页是主角**：打开 App 默认落点 = 今日复习（而非首页墙）。
3. **动效只做"反馈"不做"表演"**：翻卡、打卡、曲线更新有微反馈；没有粒子、没有吉祥物。
4. **数据说话**：所有"成长感"来自真实数据（曲线、热力图、月度报告），而不是虚拟奖励。
5. **隐私默认**：本地优先，不登录可完整体验；导出、删数据都是一键。
6. **键盘友好**：桌面端可全键盘操作（工具党的隐形刚需）。

## 八、商业与获客（工具赛道）

| 项 | 方案 |
| --- | --- |
| 免费额度 | 每日 30 卡 + 100 张卡库（覆盖体验 SRS 神奇曲线） |
| 订阅 | 25 元/月 或 198 元/年（Pro：无限卡片 / AI 成卡 / 云同步 / 多语言） |
| 买断（可选） | 398 元终身 Pro（工具用户的"买断情结"） |
| 获客 | **工具赛道不吃买量，吃口碑**：App Store 搜"闪卡/记忆/背单词"位、Reddit/知乎/HN 长文、开发者社区（"我做了个 Readwise 中文版"就是传播点） |
| 目标 | 第一年 5000 下载 / 500 DAU / 50 订阅（工具产品的健康起点比游戏低得多） |

## 九、新开发计划（比游戏版快一倍）

| 阶段 | 周期 | 交付 | 生死线 |
| --- | --- | --- | --- |
| 0 工程准备 | W1~2 | Flutter 工程 + SM-2 引擎单测 + 词库管线 + 埋点 | — |
| 1 MVP | W3~6 | 收件箱+收藏（分享面板/粘贴）+ 复习三键 + 记忆库 + 曲线 | 内测次留 > 35% |
| 2 打磨上架 | W7~10 | 50 人内测、软著隐私、商店三图、订阅墙 | 付费率 > 1.5% |
| 3 V1.1 纵深 | W11~16 | OCR/剪藏入口、Anki 导入导出、多语言词库（英/韩）、月度报告 | 周留存 > 40% |
| 4 V1.2 收藏强化 | W17~24 | 三层分类 + AI 打标 + 待归类箱、WebDAV/iCloud 同步、热力图海报 | 收藏→复习 > 40% |
| 5 V2 | W25~36 | 桌面端（Flutter 免费多端）、插件/API、FSRS 切换、内容市场预研 | 桌面周活 > 10% |

> 注：收藏管道的时机从"V1.2 游戏版"提前到**MVP 就内置**——因为收藏是工具的心脏，不是附加玩法。
> 时间对比：游戏版公测 ≈ 12~16 周 + 美术黑洞；工具版公测 ≈ **10 周，无外部依赖**。

## 结论

> **放弃的不是"有趣"，是"我做不到的游戏化"；保留的是"我做得好的科学和体验"。**
> 工具路线下，产品依然是那个"让用户记住"的产品——只是把一个亿级开发者的幻觉，换成一个独立开发者 10 周就能上线、一年能活得健康的确定性生意。
