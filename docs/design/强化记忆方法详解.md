## 一、记忆的底层规律

### 1.1 记忆的三个阶段

| 阶段 | 容量 | 持续时间 | 特点 | 对 App 的启示 |
| --- | --- | --- | --- | --- |
| 感觉记忆 | 极大 | 0.25 ~ 2 秒 | 声音、影像的瞬时缓存 | 卡片出现节奏、动画反馈要在「感知窗口」内完成 |
| 工作记忆（短时） | 7±2 个组块 | 15 ~ 30 秒 | 需要复述才能保持 | 单次信息不要超载，一次只学 5~7 个新块 |
| 长时记忆 | 近乎无限 | 数天 ~ 终生 | 靠「编码 + 巩固 + 提取」形成 | App 的终极目标是把内容送入长时记忆 |

### 1.2 Ebbinghaus 遗忘曲线

- 遗忘在**学习后 20 分钟~24 小时**内速度最快，之后逐渐放缓。
- 每一次「在将要遗忘时成功提取」，都会让下一次遗忘速度显著变慢。
- 推论：**复习时机比复习次数更重要** —— 这就是间隔重复（Spaced Repetition）的生理学依据。

### 1.3 记忆巩固与睡眠

- 新学内容先存在**海马体**，睡眠中逐步迁移到**新皮层**形成长期存储。
- 实验证明：学习后睡 8 小时的人，第二天回忆成绩明显好于熬夜者。
- 推论：**当天学的词，第二天早上的第一次复习**效率最高；App 应设计「次日晨间复习」。

### 1.4 两条记忆通路：语义记忆 & 情景记忆

- 语义记忆：词的含义、语法规则（脱离上下文，容易忘）。
- 情景记忆：与具体场景、画面、情绪绑定的经历（记得牢）。
- 推论：**把单词放进场景里教**（例句、图片、声音、真实对话），就是在把语义记忆转化为情景记忆。

## 二、六大核心记忆方法

### 2.1 间隔重复（Spaced Repetition / SRS）

**是什么**：按照遗忘曲线安排复习时间，在即将遗忘的临界点进行提取，复习间隔逐次拉长（如 1 天 → 3 天 → 7 天 → 15 天 → 30 天）。

**为什么有效**：每次临近遗忘的成功回忆，都会重新触发记忆巩固，且巩固效果随间隔拉长而增强（称为 spacing effect）。

**落地要点**：

- 用成熟算法（SM-2、FSRS、Leitner 盒）决定每张卡片的下次出现时间。
- 用户自评「忘记 / 模糊 / 记得」三个等级即可驱动算法，无需复杂操作。
- 复习量保持「每天 15~30 分钟」的可持续节奏，优于考前突击。

### 2.2 主动回忆（Active Recall / 提取练习）

**是什么**：不重复阅读，而是**尝试在脑海中（或纸面/口头）把内容调出来**，再对照答案。

**为什么有效**：提取动作本身就在加强记忆痕迹（测试效应，Testing Effect）；而「感觉看懂了」是错觉，只有提取成功才算真正记住。

**落地要点**：

- 卡片设计成「先出题、后显答案」，禁止先看答案再回想。
- 回忆失败时先「再试一次」，而不是立刻翻答案。
- 产出式任务优先：拼写、默写、跟读、造句，而不是选择题。

### 2.3 精细加工（Elaborative Encoding）

**是什么**：把新知识与已有知识建立**多维度联系** —— 联想、对比、编故事、追问「为什么」。

**为什么有效**：记忆的本质是「网络」而非「文件柜」，联结越多，提取路径越多，越不容易丢失。

**落地要点**：

- 每个新词配：例句 2~3 条、同义词/反义词、词源词根拆解、场景图片。
- 用「是否记得这个词在哪个例句里」来检验联结是否建立。
- 鼓励用户自己造一个句子（生成效应，见 2.6），自己造的记得最牢。

### 2.4 记忆宫殿（Method of Loci）

**是什么**：把待记内容按顺序放置在一个**熟悉的空间**（自己的家、每天通勤的路）里，回忆时在脑中走一遍路线。

**为什么有效**：利用人类对空间与方位极强的进化记忆能力，把抽象内容挂载到具象空间上。

**落地要点**：

- 最适合记忆「有顺序、数量大」的内容：如日语五十音五十音图顺序、英语不规则动词表、一组易混词。
- App 可提供「宫殿模板」（房间→物品→关键词位置），让用户把一组单词安放进房间。
- 对听力类内容（对话顺序、药品说明书步骤）同样适用。

### 2.5 交错练习（Interleaving）

**是什么**：不按「同一种类型连续练」，而是**把不同类型/不同难度的题目混在一起练习**。

**为什么有效**：必须先在脑中判断「这道题属于哪类、该用哪个规则」，这个「判断」过程就是强化记忆的提取练习；同时减少对「顺序提示」的依赖。

**落地要点**：

- 复习时把「昨天的新词 + 上周的词 + 语法的不同形态」混排。
- 日语中特别有效：相似假名、相似汉字、易混助词（は/が、に/で/へ）交错出现。
- 学习模式保持「同类一组」，复习模式必须打乱。

### 2.6 生成效应（Generation Effect）

**是什么**：自己「生成」答案比「阅读」现成答案记得更牢 —— 哪怕是生成后发现自己错了。

**为什么有效**：生成过程消耗了更多认知资源，并激活了努力搜索的神经通路。

**落地要点**：

- 卡片先给提示（首字母、中文意思、词根），让用户先尝试生成，再给答案。
- 开放式输入（打字/语音朗读）优先于点选式选择。
- 用户自造句、自编助记口诀功能，是生成效应的直接体现。

## 三、语言学习专属方法

### 3.1 词汇记忆

| 方法 | 说明 | 日语示例 | 英语示例 |
| --- | --- | --- | --- |
| 词根词源拆解 | 拆出词根/偏旁，成串记忆 | 汉字偏旁：氵(水)相关 → 泳、流、海；訓読み同源：行く・行き | act→action/active/activity，可见于 act 家族 |
| 以类分组 | 按主题/语义场成组记 | 餐具组：箸・皿・茶碗・スプーン | 餐厅组：appetizer/entrée/dessert |
| 反义联想 | 一个词带出对立面 | 高い⇔低い、上がる⇔下がる | hot⇔cold、buy⇔sell |
| 谐音/助记口诀 | 用母语搭桥（注意仅作辅助） | あ=a 像「啊」，い=i 像「衣」 | memory → 「美摩莉的谐音」 |
| 例句语境 | 至少 2 条例句后记忆 | 文脈 (bunmyaku)：「文脈から意味を推測する」 | "run" 的 3 种语境 |

### 3.2 语法与句式

- **规则先行 + 例子填充**：先抽象规则（て形变化），再给 5 个以上具体例子，让大脑自动归纳。
- **对比记忆（最小对立对）** ：只差一个成分的句子对比记忆，效果远超孤立记忆。
  - 日语：私は学生です / 私は学生ではありません / 私は学生でした
  - 英语：I have been living here for 5 years / I lived here 5 years ago
- **产出式应用**：看完规则立刻「套模板造句」，生成效应同样适用于语法。

### 3.3 听力与口语（声音记忆）

- **影子跟读（Shadowing）** ：跟着音频延迟 0.5~1 秒复述，训练语音回路，把「听」和「说」绑定。
- **间隔重复听音**：同一段音频在 1 天、3 天、7 天后重听，听力词汇会逐步转化为可感知词汇。
- **听写（Dictation）** ：把听到的内容写出来，是最强的声音提取练习。
- **发音纠错**：对自己的录音进行回放对比（自我监控），比单纯听更有效。

### 3.4 沉浸与输入（i+1 原则）

- 输入内容难度在「当前水平 + 一点点」最佳：完全不懂没法学，完全懂没有进步。
- **可理解性输入（Krashen 假说）** ：大量可理解的听读输入是语言习得的主要来源。
- App 可做：分级阅读/分级新闻（按用户词汇量过滤生词），读完立即用「内容回顾」测试。

### 3.5 日语特有的记忆难点与对策

| 难点 | 特点 | 对策 |
| --- | --- | --- |
| 五十音 | 44~46 个符号，纯符号记忆 | 记忆宫殿路线 + 谐音联想 + 每日 5 个新假名 |
| 汉字 | 音读/训读双系统 | 同偏旁成组教；音读对应中文读音规律；训读用词块记忆 |
| 助词 | は/が/に/で/へ 语义细微 | 最小对立对对比句 + 大量交错练习 |
| 敬语 | 尊他/自谦体系复杂 | 场景模拟对话（对客户/对前辈/对后辈） |
| 动词活用 | て形/ない形/た形 | 表格化 + 交错练习，先规则后乱序 |

### 3.6 英语特有的记忆难点与对策

| 难点 | 特点 | 对策 |
| --- | --- | --- |
| 拼写（拼读不一致） | receive/achieve 等 | 词根 + 谐音 + 听写练习 |
| 动词短语（phrasal verbs） | give up / give in / give away | 以动词为枢纽成组记，配场景例句 |
| 介词搭配 | depend on / interested in | 词块记忆（chunk），整块存储而非单词+介词拆分 |
| 不规则动词 | 三态变化无规律 | 记忆宫殿 + 交错练习 + 每日 5 个 |
| 语音弱读连读 | wanna / gonna、连读吞音 | 影子跟读 + 听写 + 录音对比 |

## 四、影响记忆的生活因素

### 4.1 睡眠
- 睡眠不足直接削弱海马体功能；学习后的深度睡眠决定巩固质量。
- **产品建议**：提醒用户「睡前 10 分钟复习今天所学」，「睡醒后 5 分钟快速回忆」，形成记忆节律。

### 4.2 运动
- 有氧运动促进海马体神经新生（BDNF 分泌），长期运动者记忆力显著更好。

### 4.3 注意力与专注
- 记忆的第一道闸门是**注意** —— 没注意到的东西不可能记住。
- 分心（手机通知打断）会显著降低编码质量。
- **产品建议**：学习会话内开启「专注模式」，单次会话 15~25 分钟（番茄钟）。

### 4.4 情绪与多巴胺
- 积极情绪和「小胜利」反馈（打卡、徽章、连击）促进多巴胺释放，增强记忆巩固。
- 焦虑和挫败感反而抑制提取 —— 复习失败的呈现方式要温和（「明天再见它」而非「你又错了」）。

### 4.5 多模态：视觉 + 听觉 + 动觉
- 同一内容用多通道编码（图片 + 声音 + 手写/跟读动作），形成冗余记忆痕迹。
- **产品建议**：默认卡片同时显示图片、发音音频、例句；支持手写、跟读、打字三种回忆方式。

> **产品化注记**：本篇为通用记忆科学方法论；具体产品映射见《记忆教练App架构设计》《记忆教练-收藏管道设计》。下文第五章为记忆教练工具版的功能映射（游戏化方案已随宫殿一起归档）。

### 5.2 核心学习流设计（示例）

```
[收藏] 任意 App 分享/剪贴板/拍照 → 记忆教练收件箱（零打断）
   ↓  AI 成卡（离线词库兜底，可编辑）
[归位] 自动打标归档（几秒完成，或留「未分类」不管）
   ↓  SRS 排期（明天首复）
[复习] 混合队列：今日到期卡 + 薄弱加权（先猜后看，三键评级）
   ↓
[节律] 睡前提醒 + 晨间提醒（本地通知）
   ↓
[报告] 遗忘曲线 / 热力图 / 30 天对比 / 薄弱 Top3
```

### 5.3 数据与个性化

- 记录每张卡片的**历史回忆成功率**，生成个人遗忘曲线，反向校准 SRS 参数。
- 统计薄弱类型（如「日语助词」「英语介词搭配」），在复习队列中自动提高其出现频率。
- 用用户自己的错误数据生成「专属易错集」，再次进入 SRS 队列。
- **投影原则**：统计与"已掌握/冷置"全部由 review_log 派生，无法手动篡改（架构铁律）。

### 5.4 记忆教练 MVP 功能优先级建议

## 六、SRS 算法实现详解

目的：把「间隔重复」落到实处，这是整个 App 的核心引擎。三种主流方案，从简单到高级：

### 6.1 SM-2 算法（SuperMemo 2，Anki 长期默认）

每个复习卡维护三个参数：**间隔 I（天）**、**难度因子 EF（初始 2.5）**、**连续答对次数 n**。每次复习根据用户的「质量评分 q（0~5）」更新参数：

```
# 伪代码
review(card, q):
    if q < 3:                        # 答错 → 重学
        card.n = 0
        card.I = 1                   # 明天再见
        card.EF = max(1.3, card.EF - 0.2)
    else:                            # 答对
        if card.n == 0:   card.I = 1
        elif card.n == 1: card.I = 6
        else:             card.I = round(card.I * card.EF)
        card.n += 1
        card.EF = max(1.3, card.EF + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02)))
    card.next_review = today + card.I
```

App 三按钮映射：**忘记**（q≤2）→ 间隔重置为 1 天，EF 微降；**模糊**（q=3~4）→ 间隔不变或折半；**记得**（q=5）→ 间隔 ×EF。典型间隔序列：1 → 6 → 15 → 30 → 60 天。

### 6.2 Leitner 盒（最容易落地）

- 新卡进**盒 1**，每日复习；答对升盒：盒 2 每 2 天 → 盒 3 每 4 天 → 盒 4 每 10 天 → 盒 5 每 30 天。
- 答错**降回盒 1** 重新爬升。
- 优点：实现零成本、间隔直观、天然适合展示「记忆层级」做游戏化（盒 5 = 金色卡组）。
- 缺点：不区分卡片个体难度，粒度粗。适合 MVP 起步。

### 6.3 FSRS（Free Spaced Repetition Scheduler，进阶）

- 数据驱动的概率模型：用**历史复习记录**预测每张卡片的「记忆保留率」（retention），按用户设定的目标保留率（如 90%）精确安排下一次复习时间。
- 支持一天内多次复习日志、按天粒度调度、可选优化器自动调整参数。
- 落地建议：**先用 SM-2 起步，积累 2~4 周数据后切换 FSRS**（参考开源实现 fsrs4anki / ts-fsrs）。

### 6.4 选型建议

| 方案 | 实现复杂度 | 调度精度 | 适用阶段 |
| --- | --- | --- | --- |
| Leitner 盒 | ★☆☆ | 一般 | MVP 快速上线 |
| SM-2 | ★★☆ | 较好 | 起步推荐（经 Anki 大规模验证） |
| FSRS | ★★★ | 最好 | 数据积累后的进阶优化 |

## 七、词库与复习数据结构设计

### 7.1 词条模型（Words）

```json
{
  "id": "ja-000123",
  "lang": "ja",
  "headword": "文脈",
  "reading": "ぶんみゃく",
  "romaji": "bunmyaku",
  "ipa": null,
  "audio_url": "https://.../bunmyaku.mp3",
  "senses": [
    {
      "pos": "名词",
      "gloss": "上下文，语境",
      "examples": ["文脈から意味を推測する"]
    }
  ],
  "word_class": "名词",
  "tags": ["N1", "阅读"],
  "level": "N1",
  "etymology": "文(文字/文章) + 脈(脉络/脉路) → 文章的脉络",
  "related": ["前後関係", "context(英)"]
}
```

要点：

- 日语词条必须同时保存 `headword`（汉字表记）与 `reading`（假名/罗马字），英语则保存 `ipa`（音标）与拼写。
- `senses` 复数义项 + 每义项至少 2 条例句，满足「精细加工」的多维编码需求。
- `etymology` 存词根/偏旁拆解，支撑词根串记法。
- 同义词/反义词、主题标签用于「以类分组」和交错练习来源。

### 7.2 卡片类型（CardTypes，决定复习交互）

| 类型 | 问 → 答 | 对应记忆方法 |
| --- | --- | --- |
| RECOGNITION | 见词 → 选/认出释义 | 识别记忆（低强度提取） |
| RECALL | 见义 → 打字拼写/默写 | 主动回忆（高强度提取） |
| PRONUNCIATION | 见词 → 跟读录音，AI 评分 | 声音回路 + 生成效应 |
| LISTENING | 听音 → 辨义/选词 | 听力词汇转化 |
| SENTENCE | 补全/排序句子 → 对照 | 语法语境 + 精细加工 |
| KANA / KANJI | 假名↔读音、汉字↔音读/训读 | 日语符号记忆特化 |

一个词可挂**多张卡**（如 RECALL + PRONUNCIATION + LISTENING），各自独立走 SRS 队列 —— 这正是「多模态编码」的数据化表达。

### 7.3 复习记录表（review_log）

| 字段 | 说明 |
| --- | --- |
| id / card_id / user_id | 主键与关联 |
| reviewed_at | 复习时间（精确到秒，绘制遗忘曲线用） |
| quality | 0~5 质量分（三按钮映射 2/4/5） |
| interval_days / ease_factor | 算法输出的间隔与难度因子 |
| state | new / learning / review / relearning |
| source | 学习 / 复习 / 错题重练（分析薄弱点） |

用途：每天数十条日志就能滚动生成「个人遗忘曲线」与「七日内最薄弱卡片 Top 榜」。

### 7.4 用户模型（users + user_settings）

- 目标语言、水平自测（JLPT / CEFR）、每日目标（新词数 / 复习预算分钟数）。
- 学习时段偏好（晨间 / 睡前复习包的推送时间）。
- 交错权重：用户可调「薄弱类型出现频率」，如把「浊音假名」权重拉高。

### 7.5 表关系简图

```
users 1 ── n review_log n ── 1 cards
cards n ── 1 words
words n ── n word_notes（用户自建助记 / 自造句）
users 1 ── n word_notes
```

### 7.6 数据流闭环

```
词库（公开词表清洗 + 自建） → 学新词时生成多张卡 → SRS 排期
    → 复习写入 review_log → 算法更新间隔 & 个人曲线
    → 首页待复习队列 → 周期报表（薄弱点回灌交错练习）
```
