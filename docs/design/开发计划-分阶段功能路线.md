## 二、阶段 0：工程准备（W1~2）

| 模块 | 功能点（验收标准） |
| --- | --- |
| Flutter 工程 + CI | 双端可编译；自动化跑单测；代码规范 lint 通过 |

## 三、阶段 1：MVP（W3~6）

### 3.1 功能清单

| 模块 | 功能点（验收标准） |
| --- | --- |
| 收藏-分享面板 | iOS/Android 系统分享扩展出现"记忆教练"，选中内容进入收件箱（不弹任何确认） |
| 收藏-剪贴板 | 复制文本后 App 内轻提示"有内容要收藏？"（可设置关闭） |
| 收藏-手动 | 右上角 +：新建卡（词条/语录/灵感，Markdown 输入，支持标签） |
| 成卡引擎 | 收藏文本 → AI 补释义/例句/发音（离线词库兜底；置信低标"待确认"）；全部可编辑 |
| 复习闭环 | 闪卡先猜后看；三键评级（忘了/模糊/记得）→ SM-2 更新；今日任务数；断点续复习 |
| 遗忘曲线 | 个人曲线 vs 理论曲线叠加图（fl_chart）；周视图 |
| 记忆库 | 搜索（全文）；筛选（语言/来源/状态）；分组视图（默认库：未分类） |
| 免费额度 | 非 Pro：日 30 卡 + 100 卡库（超限提示，不打断复习中） |
| 订阅墙 | 第 3 天触达（有复习数据后）；26 元/月、198 元/年、398 元买断（占位） |

### 3.2 验收（M1）

- 内测 50 人：收藏→复习转化 > 30%（早期）、复习完成率 > 60%
- 次留 > 35%、7 日 > 25%；AI 成卡可编辑率 < 20%（用户不改=质量好）
- **不达标 → 重做核心交互（不带上架）**

## 四、阶段 2：内测打磨与上架（W7~10）

| 模块 | 功能点（验收标准） |
| --- | --- |
| 内测迭代 | 每周 1 版；修复优先级 Top10（卡顿/歧义/成卡错误/付款失败） |
| 上架物料 | 软著、隐私政策（含"数据默认本地""可导出删除"声明）、商店三图（叙事：划进来→自动复习→曲线下降）、App 图标（外包/AI） |
| 订阅收尾 | 双端商店内购接入 + 服务端校验回执 + 漂移防重复扣费 |
| 冷启动 | 500 邀请码（首年 8 折）+ 3 个社群渗透 + 上架当周内容营销启动 |
| 导出 | 本地 zip 导出（media+JSON）——上市即具备（所有权承诺） |
| 数据看板 | 埋点巡检脚本 + 周报模板（收藏/复习/付费漏斗） |

**M2 生死线**：付费率 > 1.5%、次留稳定 > 30%；否则停投流（工具本来就口碑起步），回调定价/漏斗。

## 五、阶段 3：V1.1 纵深（W11~16）

| 模块 | 功能点（验收标准） |
| --- | --- |
| OCR 收藏 | 拍照/截图 → 系统 OCR/mlkit → 进管道（图片存为卡面）；中文/日文识别可用 |
| 剪藏正文 | 分享面板：标题+URL+摘要（<1KB）入库；原文不托管（版权红线） |
| **Anki 兼容** | 导入 .apkg（标准牌组）→ 建成卡；导出当前库 → .apkg；词条字段映射表（word/reading/meaning） |
| 月度报告 | 上月统计（收藏/复习/掌握率）+ 30 天对比见证 + 薄弱 Top3 + 分享海报 |
| 多语言词库 | 英语频道（COCA 前 2000，IPA，TTS 离线包）；日语扩至 2000（N5~N4） |
| 桌面端准备 | 自适应布局改造（宽屏三栏预览），不入上架范围 |

**M3 验收**：周留存 > 40%；Anki 导入成功率 > 95%（10 个测试牌组）；月报分享率 > 10%。

## 六、阶段 4：V1.2 收藏强化（W17~24）

| 模块 | 功能点（验收标准） |
| --- | --- |
| 三层分类 | 库/子集/条目；系统预置库（工作/日语/灵感）+「未分类」兜底；多标签交叉 |
| AI 打标 | 本地主题词表 + LLM 增强（批量、JSON 输出、低置信<0.6 进待归类）；语言自动标（ja/en） |
| 待归类机制 | 收件箱角标轻提示；14 天未归自动入「未分类」（不再提醒） |
| 按库复习 | 复习页筛选器（单库/多库）；默认混合队列（交错原则） |
| 分库统计 | 每库头部：掌握率/复习量/薄弱标签 |
| **云盘同步（存储 B 档）** | iCloud Drive + WebDAV（坚果云等）：Wi-Fi+充电增量备份；恢复向导；媒体仅备份到用户云盘（服务器 0 存储铁律） |
| 热力图 | GitHub 风格复习日历（跨月） |

**M4 验收**：收藏→复习转化 > 40%；自动打标准确率 > 80%；按库复习使用率 > 40%；**服务器新增存储 = 0 核对单签字**。

## 七、阶段 5：V2 多端与平台化（W25~36）

| 模块 | 功能点（验收标准） |
| --- | --- |
| 桌面端 | Flutter Windows/Mac 打包上架；全键盘复习（空格翻卡/1-2-3 评级）；宽屏三栏（库-列表-编辑） |
| FSRS 升级 | review_log ≥ 4 周数据后切换；A/B 对照（间隔预测偏差） |
| 云同步 C 档 | 账号（可选登录）+ 云端日志回放（append-only 合并，删号即删）；订阅跨端校验 |
| 多语言 | 韩语频道（谚文入门 + 500 词）；语言维统计/筛选 |
| 数据 API（预研） | 只读 API（个人数据导出/自动化脚本），暂不对第三方开放 |
| B 端微探索 | 教师"布置复习包"（班级码，统计回执）——问卷验证 |

**M5 验收**：桌面周活 > 10%（老用户复用）；FSRS 切换后复习完成率不降；云同步丢数据率 = 0（测试集）。

## 八、跨阶段依赖

```
阶段 0 ── SM-2 + drift + 埋点 ──→ 全部阶段（地基）
阶段 1 ── 收藏入口 + 成卡 + 复习 ──→ 阶段 2 订阅/漏斗
阶段 1/3 ── 月度报告依赖 review_log 回放 ──→ 阶段 3
阶段 3 ── Anki 兼容（导入渠道）──→ 阶段 4 分类打标（批量来源增加）
阶段 3/4 ── 云盘同步 B 档先于 C 档（通道复用）──→ 阶段 5
阶段 5 ── FSRS 依赖 ≥4 周日志 ──→ 不可提前
```

**关键提示**：
- 埋点先于任何功能（否则指标无法验收）。
- Anki 兼容最好在 W12 前（导入用户是早期口碑）。
- B 档云盘（W17+）是 C 档（W25+）的通道基础，顺序不可颠倒。
- FSRS 永远可后切（日志完整即可），不必赶早期。

## 十一、每阶段验收清单（Checklist）

- [ ] **M0**：flutter test 全绿、三 Tab 可切换、埋点 10 事件上报成功
- [ ] **M1**：从剪贴板到形成复习任务 ≤ 60 秒演示路径；曲线页有真实数据
- [ ] **M2**：商店三端物料齐、订阅真实可购（沙盒+正式）、出口 zip 可用
- [ ] **M3**：OCR 3 种语言各 10 张通过；Anki 10 个牌组导入成功率 100%→95% 验收
- [ ] **M4**：打标 demo 100 条准确率 ≥ 80%；云盘恢复 2 台设备数据一致
- [ ] **M5**：桌面键盘全流程可复习；FSRS 切换 A/B 无回归；同步测试集零丢失

> **执行纲领**：每个周日收一次本阶段的 Checklist；不做完不进入下一阶段；生死线不过 → 停下来改方向（工具版的最小成本就是"随时掉头不心疼"）。
