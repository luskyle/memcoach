## 二、Flutter 详解（重点章节）

### 2.1 为什么是 Flutter（工具版六条理由）

| # | 理由 | 对记忆教练的意义 |
| --- | --- | --- |
| 1 | **一套代码多端**（iOS/Android/Windows/macOS/Linux/Web） | V2 桌面端零重写（记忆教练开发计划 M5 的硬需求） |
| 2 | **离线优先一等公民** | SRS 引擎、词库、媒体全本地，断网秒开（产品核心承诺） |
| 3 | **UI 一致性强 + 性能可压**（Impeller 渲染） | 闪卡翻转/图表滚动 60fps；低端机可开省电模式 |
| 4 | **单一语言 Dart**，类型安全 | 一个人维护的代码库，Dart 的静态分析让重构安全 |
| 5 | **所有关键能力有成熟包** | 存储/状态/图表/通知/分享/OCR 全部现成（2.5 清单） |
| 6 | **免费开源、无授权费** | 对独立开发者零前期成本 |

**对比结论**（工具版视角）：React Native 的生态更散（状态/导航/原生桥各自为政）；Kotlin Multiplatform 适合有原生团队的公司；原生双端 = 双倍工作量。**Flutter 是单人工具型产品的当前最优解。**

### 2.2 生态与版本策略

- **版本线**：采用**当前最新稳定线**（Flutter 3.x 序列，以官方 stable 为准），发布通道只做 `stable`，不追 beta/master。
- **渲染引擎**：Impeller 已逐步成为 iOS/Android 默认渲染引擎（Skia 保留为 desktop/降级路径）——对记忆教练的意义：滚动列表 + 卡面动画的帧率与内存表现足够好。
- **Dart 版本**：跟随 Flutter 锁版（不可独立升级），升级时先跑 `dart analyze` + 全量测试。
- **升级节奏策略**：**半年一升**（紧跟一个 LTS 节奏），每次升级前读 `breaking-changes` 清单；不追新功能。

### 2.3 状态管理选型（Riverpod 推荐）

| 方案 | 上手 | 编译期安全 | 测试性 | 生态现状 | 结论 |
| --- | --- | --- | --- | --- | --- |
| **Riverpod** | 中 | ✅（codegen） | ✅ | 活跃，官方推荐定位 | **推荐** |
| Provider | 低 | 弱 | ✅ | 成熟但停滞维护 | 备选 |
| Bloc | 高（样板多） | ✅ | ✅ | 活跃 | 工具型偏重 |
| GetX | 低 | 弱 | 弱 | 争议大 | 不用 |
| setState/Inherited | — | — | — | — 仅小型页内状态 |

**选 Riverpod 的三个理由**：
1. **依赖可覆盖**：Repository/SRS 引擎可注入 fake，单测不碰平台通道。
2. **状态可观察**：复习进度/收藏计数从 provider 派生，UI 自动刷新。
3. **编译期安全（codegen）**：一个人写代码也不怕改字段漏引用。

### 2.4 工程结构规范（feature-first）

```
lib/
  main.dart / app.dart
  core/           # 主题、路由、错误处理、日志
  data/           # drift 表、repository、本地文件访问
  domain/         # SRS 引擎、成卡逻辑（纯 Dart，无 Flutter 依赖）
  features/
    inbox/        # 收件箱（列表、待归类角标）
    review/       # 复习（闪卡、评级、曲线）
    library/      # 记忆库（搜索、筛选、分组）
    settings/     # 订阅、云盘、导出、隐私
  shared/         # 通用组件（卡片、空态、弹层）
```

> 约束：`domain/` 不 import Flutter 任何包——SRS 与成卡规则可单独跑 `dart test`，不依赖模拟器（详见 2.10）。

### 2.5 六大模块的 Flutter 实现蓝图

| 模块 | Widget/服务 | 关键包 | 要点 |
| --- | --- | --- | --- |
| 三 Tab | `NavigationBar` + `IndexedStack`（保状态） | 内置 | 复习页为默认落点；切的 Tab 不重建（IndexedStack） |
| 闪卡复习 | `AnimatedSwitcher`/`TweenAnimationBuilder` 翻转 + DRAG 手势 | 内置 | 先猜后看：正面问题/背面答案两态；评级按钮震动反馈 |
| 图表 | 遗忘曲线折线 + 热力图 | **fl_chart** | 曲线用 `LineChart`；月度报告复用同一数据源 |
| 收藏入口 | Share 扩展（原生）→ 进 inbox | `share_plus`/原生扩展 | 移动端系统分享；剪贴板用 `Clipboard` + 定时器监测 |
| 本地存储 | drift Database + Hive | **drift**/**hive** | 见第四章 |
| 本地通知 | 每日复习提醒 | **flutter_local_notifications** | 晨间/睡前场景；用户可关 |
| 列表 | 收件箱/记忆库长列表 | 内置 `ListView.builder` | 1000+ 条不卡：itemKey 稳定、图片异步解码 |

### 2.6 平台通道与原生集成（6 个原生能力）

| 能力 | 实现方式 | 备注 |
| --- | --- | --- |
| ① 系统分享扩展 | iOS `Share Extension` / Android `ACTION_SEND`，共享区写 `SharedPreferences`+标志位，App 启动时收割 | 工具核心入口，W3 就要通 |
| ② 剪贴板监测 | `Clipboard.getData` 前台定时轮询 + 系统粘贴板变化 API（iOS 17+） | 轮询节流（>3s），可设置关闭 |
| ③ OCR | iOS `Vision`（VNRecognizeTextRequest，支持日/英）；Android `Google ML Kit` | 中文/日文/英文三语识别 |
| ④ 内购 | **in_app_purchase**（官方包，双端商店） | 订阅+非消耗；服务端回执校验 |
| ⑤ 通知权限 | permission_handler + local_notifications | 合规引导文案 |
| ⑥ 云盘 | iCloud Drive 用 `file_picker` 开放目录（uidocument = 用户配额）；WebDAV 用 `webdav_client` | 存储方案 B 档 |

> 说明：Share Extension/OCR 是原生代码（Swift/Kotlin）嵌入 Flutter 工程，通过 MethodChannel 暴露方法——这是 Flutter 工程不可避免的最小原生面，**总量约 300~500 行原生代码**，是单人可维护的量级。

### 2.7 性能与包体优化清单

| 项 | 措施 | 目标 |
| --- | --- | --- |
| 启动 | `--obfuscate --split-debug-info`；关闭无用插件 lazy-init；首屏只加载收件箱 | iOS < 1.5s / Android < 2s |
| 包体 | 只打包用到的平台；图片资源 webp；treeshake icon 字体 | 单包 < 60MB（含词库） |
| 滚动 | `ListView.builder` + 阈值分页（每页 50 条）；图片 `ResizeImage` 解码降采样 | 1000 条列表滚 60fps 低端机 |
| 内存 | 闪卡图片 LRU 缓存（`cached_network_image` 换成本地缓存实现） | 无 OOM |
| 后台 | 复习页保活（`WidgetsBindingObserver` 生命周期处理） | 中途退出不丢进度 |

### 2.8 桌面端复用（V2 计划）

- Flutter 同代码库出 Windows/macOS：桌面端分享面板不存在 → 用"拖文件进窗口 + 粘贴监听"替代收藏入口；键盘快捷键（空格翻卡、1/2/3 评级、Ctrl+K 搜索）走 `Shortcuts`/`Actions`。
- **tablet/desktop 自适应**：`LayoutBuilder` 宽屏三栏（库-列表-编辑）；移动端一栏。
- 桌面打包：Windows 用 MSIX/zip 分发；macOS 上架 App Store 需公证（developer ID）。

### 2.9 国际化与无障碍

- 三语：**zh-CN / en / ja**（`flutter_localizations` + `ARB`）。收藏内容多语言混排——**界面语言 ≠ 内容语言**，独立设置。
- 无障碍：闪卡区域 `Semantics` 标签（正面/背面朗读）；配色对比度 AA；字号可缩放（工具用户有长辈场景）。

### 2.10 测试策略

| 层 | 工具 | 覆盖 |
| --- | --- | --- |
| 纯 Dart 单测 | `dart test` | **SRS 引擎（20+ 用例）**、成卡规则、去重逻辑（CI 必跑） |
| Widget 测试 | `flutter test` | 三 Tab 切换、闪卡翻面、评级按钮、付费墙展示条件 |
| 集成测试 | `integration_test` | 关键路径：收藏→成卡→复习→曲线出数据（真机冒烟） |
| 原生回归 | 手动清单 | Share 扩展、OCR 各平台真机验证 |

> CI：GitHub Actions 免费额度跑 `analyze` + `dart test` + `flutter test`，Windows runner 打包。

### 2.11 国内开发环境注意

- **pub 镜像**：`PUB_HOSTED_URL=https://pub.flutter-io.cn`（国内网络必需），CI 与本地统一。
- Android 发布：打包签名（keystore）、各渠道包（腾讯应用宝/小米/华为/OPPO/vivo）渠道包用 `--flavor` 区分；上架需软著。
- iOS：Xcode 侧 Signing 用个人开发者账号；审核注意：订阅未购买状态不能隐藏免费功能按钮。
- 合规 SDK：如接统计，选可私有化部署的轻量方案（自建埋点上报即可，见第七章）。

### 2.12 Flutter 升级与维护风险

| 风险 | 对策 |
| --- | --- |
| 大版本 breaking change | 半年一升；升级前读官方 breaking 清单；先升分支跑全量测试再合主 |
| 插件停维护 | 选"官方或超大社区"包（下表全部满足）；runtime 记依赖清单备选 |
| 国内镜像不稳定 | CI 加 `--offline` 缓存策略；锁 lockfile |
| 桌面端 API 波动 | V2 再启用桌面；移动端先行（桌面需求晚 6 个月） |

## 三、SRS 引擎

（沿用前版结论，记忆教练工具版不变）

- **MVP**：自写 SM-2 纯函数（<100 行）在 `domain/`，20+ 单测覆盖忘记/模糊/记得、间隔边界、EF 钳制。
- **升级**：FSRS（open-spaced-repetition 系）——`review_log` 字段完整（quality/interval/state），≥4 周数据后无缝切换。
- 引擎永远**本地纯函数**：离线可跑、可单测、可整体替换（2.10 已纳入 CI）。

## 四、本地存储

| 选型 | 职责 | 理由 |
| --- | --- | --- |
| **drift**（SQLite ORM，官方推荐路线） | words/cards/items/review_log/collections | 类型安全、迁移、查询强；app_workspace 需原生 path |
| **Hive** | 缓存：热力图聚合、最近浏览、设置 KV | 轻量读快，不做关系查询 |
| 本地文件 | media/（压缩图）、导出 zip | path_provider 目录 |

- 存储路径规划（记忆教练App架构 §7）：`<sandbox>/museum/`（media/originals/clips/export）+ `museum.db`（drift）。
- 迁移策略：drift `MigrationStrategy`（schemaVersion 递增 + 备份旧库）；破坏性迁移前自动导出 `.bak`。
- 体量预估：10 万卡 + 100 万 review_log ≈ SQLite 单文件 < 500MB（可接受，SQLite 处理此量级轻松）。

## 五、AI 与成卡引擎

| 环节 | 方案 | 成本/风险 |
| --- | --- | --- |
| 词条补全（释义/例句/发音标注） | 批量离线生成：通义千问/DeepSeek 档 + 抽检 5~10% | 万卡一次性几十~几百元 |
| 运行时成卡 | **本地兜底优先**：官方词库/Tatoeba 命中 → 离线直配；未命中才走 LLM，限流 + 结果缓存 | 单次 < 0.01 元 |
| 内容安全 | 成卡结果强制 JSON 校验 + 长度/字段约束；敏感词过滤 | 出问题可回退离线词库 |
| 多语言 | LLM 按源语言标注 `lang`，日/英/中同管线 | 语言自动标进分类（记忆教练-分类 §3） |

**原则（不变量）**：一切 LLM 输出进库前可编辑；一切生成内容标"AI 生成"来源字段；运行时调用限额（免费用户每日 N 次，超限走兜底词库）。

## 十、技术风险与选型结论总表

| 决策点 | MVP | V1.1 | V2 |
| --- | --- | --- | --- |
| 客户端 | **Flutter**（stable 线） | 同左 | + 桌面端 |
| 状态管理 | **Riverpod**（codegen） | 同左 | 同左 |
| SRS | 自写 SM-2（纯函数） | 同左 | 切 FSRS |
| 存储 | drift + Hive | 同左 | + 冷库归档 |
| 收藏输入 | 分享扩展 + 剪贴板 + 手录 | + OCR | + 拖拽（桌面） |
| AI 成卡 | 离线词库优先 + LLM 兜底 | + 剪藏摘要 | 限流优化 |
| TTS | 系统兜底 | 离线批量包 | 周更内容包 |
| 云 | 无 | B 档（用户云盘） | C 档（云端日志） |
| 图表 | fl_chart | 同左 | + 报表导出 |
| 测试 | dart test + widget | + 集成测试 | 桌面冒烟 |

**风险 TOP5**：Flutter 大版本升级 breaking（半年节奏控制）；插件停维护（只选官方/超大社区包）；OCR 三语精度不齐（降级：手动输入）；iCloud 国内可用性（WebDAV 双通道）；LLM 成卡质量（离线兜底 + 可编辑）。

> **一句话技术结论**：记忆教练的技术栈全部收敛到一个"一个人记得住"的清单里——**Flutter + Riverpod + drift + SM-2/FSRS + 离线优先 + 用户云盘**；唯一原生面是 300~500 行分享/OCR 桥接。没有一处需要团队、美术或预付款大额工具。
