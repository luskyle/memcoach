# 拾忆：收藏管道设计

> 工具版核心模块（替代已归档的《收藏+记忆模式设计》）：**收藏不是"附加玩法"，而是产品的心脏**——用户从任何 App 划进来，内容自动变成记忆卡进入复习队列。
> 一句话理念：**收藏即承诺——"我收藏的东西，会被拾忆替我记住"。**

## 一、管道定位

```
任何 App / 任何场景
   │  分享面板 / 剪贴板 / 拍照 / 手录
   ▼
拾忆收件箱（待整理）
   │  AI 成卡（可编辑）＋ 自动打标
   ▼
记忆库（卡片） → SRS 复习队列 → 复习日志 → 统计/月报
```

- **管道优先级 = 产品优先级**：收藏入口的顺滑度决定了产品生死（用户收藏时被打断 = 流失）。
- 与笔记类产品的本质区别：笔记收藏 = 归档动作（入库即结束）；拾忆收藏 = **记忆动作的开始**（入库即进入复习）。

## 二、四个收藏入口

| 入口 | 交互 | 优先级 |
| --- | --- | --- |
| ① 分享面板 | 任何 App 的"分享"里出现拾忆（iOS/Android 系统级），选中即存入收件箱 | **P0（MVP）** |
| ② 剪贴板监听 | 复制文本后 App 内出现"剪贴板有内容要收藏吗"轻提示（可关闭） | P0（MVP） |
| ③ 拍照 / OCR | 拍书页/黑板/路牌，OCR 成文字进管道；照片存为卡面 | P1 |
| ④ 手动输入 | 右上角 "+" 新建卡片（词条/语录/灵感，Markdown 支持） | P0（MVP） |

**入口规则**：收藏永远 ≤1 次点击 + 0 次等待；收件箱内可批量处理，但收藏瞬间不做任何"整理确认"（防打断）。

## 三、收藏 → 成卡流水线

```
原始内容（文本/图片）
  → 去重（指纹：同一 URL/文本不再重复入库，合并提示）
  → 压缩（图片 1280px/70%；剪藏只存引用+摘要，不托管全文）
  → AI 成卡：补 释义 / 例句 / 发音（词条类）或 摘要 / 要点（文章类）
  → 可编辑（一键全改；低置信度标注"待确认"）
  → 入记忆库（默认分组：未分类） + SRS 首次排期（明天首复）
```

**成卡规则**：
- 本地优先命中官方词库 → 直接关联官方卡（去重、复用多模态素材）；未命中才走 AI。
- AI 生成内容一律可编辑、可删除；抽检规则（比例 5~10%）控质量。
- 多语言共存：中日英条目混排，语言维筛选复习（分类机制见《拾忆-内容分类机制设计》）。

## 四、防囤积机制（工具版）

> 目标：防止"只收藏不复习"变成相册/剪藏夹。**不惩罚、不强迫，用状态机引导。**

| 阶段 | 触发 | 表现 |
| --- | --- | --- |
| 已收藏 | 入库 | 收件箱显示，未进入复习 |
| 待学习 | 首次复习后 | 进入记忆库正式卡片（学习态） |
| 疏于复习 | 超过 1 个 SRS 间隔未复习 | 复习页显示"积压 N 条"，曲线开始下滑（数据说话） |
| 长期冷置 | 30 天未复习 | 并入"冷库"视图（不删除），月报里提示 |

- **learned 门槛**：只有"至少完成 1 次复习"的条目才算"已学习"——统计与"已掌握"都以真实复习为基础（投影原则，无法假装）。
- 文案基调：数据中性（"你有 23 条内容在等一次复习"），不制造焦虑。

## 五、月度报告：成长见证（替代时间胶囊）

| 元素 | 内容 |
| --- | --- |
| 数据回顾 | 本月收藏 N 条 / 复习 M 次 / 掌握率 x% |
| 对比见证 | "30 天前你答错的 3 条，今天全部答对"（review_log 回放） |
| 薄弱提示 | 最常忘的语言/主题/来源 Top3（驱动交错加权） |
| 热力图 | GitHub 风格复习日历（跨月对比） |
| 分享卡 | 一键生成"我的记忆资产"海报（含邀请码） |

- 月度报告 = 工具版的"情绪价值"（成长见证），全部数据真实，无虚构奖励。

## 六、验证指标

| 指标 | 达标线 | 说明 |
| --- | --- | --- |
| 收藏 → 复习转化率 | **> 40%** | 管道有没有真正驱动学习（产品生死线） |
| 收藏后 24h 内首复率 | > 50% | 管道顺滑度 |
| 剪藏/OCR 使用占比 | < 30%（不喧宾夺主） | 防止变成"剪藏工具" |
| 冷置条目（30 天未复习）占比 | < 20% | 防囤积机制是否生效 |
| 月度报告分享率 | > 10% | 成长见证的传播力 |

> **一句话**：收藏管道做到"零等待入库、一条链成卡、复习队列接住"，拾忆就从"又一个笔记 App"变成"会替你记住的工具"。
