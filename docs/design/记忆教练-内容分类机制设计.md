## 一、三层分类模型

```
库 Collection（主题域）      例：「工作」「日语」「读书笔记」
  └── 子集 Series（子主题）     例：「日语」→「N4词汇」「助词」
        └── 条目 Item（单卡）    例：单词/语录/灵感
```

- **三层封顶**：深层级 = 整理负担。
- **多标签交叉**：一条可属多个库（主库唯一，决定默认归属视图）。
- 默认库「未分类」接管一切自动打标失败/用户不整理的条目——**永远有地方去，永远不逼人分类**。

## 二、五个分类维度

| 维度 | 谁管理 | 用途 |
| --- | --- | --- |
| 主题（主分类） | AI 打标 + 用户可改 | 库/子集归属；按库复习与统计 |
| 语言（副标签） | AI 自动 | 复习过滤（只练日语）、多语言统计 |
| 来源（副标签） | 系统自动 | 分享/剪贴板/拍照/手录/导入；运营分析 |
| 时间（滤镜） | 系统自动 | 月度报告、热力图、最近学习排序 |
| 状态（投影） | SRS 派生 | 待学习/学习中/已掌握/冷置；**不可手动改** |

> 用户只做"这属于哪？"一个决定；其余全自动（与已归档分类设计一致，无馆徽/馆级/游戏化）。

## 三、AI 自动打标

```
有文本 → 本地主题词表命中（置信 90%+）→ 直接归库
      → 未命中 → LLM 增强（批量合并请求，输出 JSON 含 language/theme/confidence）
纯图片 → 轻量图像标签 → 实体词映射主题词表
置信度 < 0.6 → 进「待归类」提示（收件箱角标），不硬塞
超过 14 天未归 → 自动落入「未分类」库（不再提醒）
```

- 预设主题树（初始 12~16 个一级库 + 每库 3~6 子集），覆盖收藏高发域：工作/日语/英语/读书/灵感/健康/代码/生活清单等。
- **多语言原生**：日语词自动标 `ja`（核心卖点：混合收藏、按语言复习）。

## 四、手动干预与防整理负担

| 动作 | 入口 | 说明 |
| --- | --- | --- |
| 改库/拖拽 | 条目详情 / 记忆库拖拽 | ≤1 次/条 的预期频率 |
| 建库/改名 | 记忆库页长按 | 用户自己的体系 |
| 批量移动 | 多选模式（首版可不做） | 有数据后再加 |

**三条铁律（沿用）**：分类永远可跳过；一次动作完成分类；UI 不出现"标签管理/批量整理"大入口——**整理是副作用，不是功能**。

## 五、分类的出口：复习筛选与统计

工具版里分类的价值全部投射到三个真功能上：

| 出口 | 说明 |
| --- | --- |
| **按库复习** | 复习页筛选器：今日只复"工作库"/"日语 N4"（情境线索→情景记忆）；默认仍是全库混合（交错原则不破） |
| **分库统计** | 每个库的掌握率/复习量/薄弱点（记忆库页每个库头部一条数据条） |
| **薄弱加权** | 分类维度自动进入交错队列权重：最弱的语言/主题出现频率更高（数据驱动个性化） |

> 无任何虚拟奖励出口（档案版有馆徽/金光）——工具的价值陈述是数据，不是奖章。

## 六、状态维度：投影原则

```
状态（待学习 / 学习中 / 已掌握 / 冷置）
   = SRS 状态 + review_log 派生（实时计算、不可手动改）
```

- 筛选用，不可改，无法假装掌握。
- 冷置（30 天未复习）→ 冷库视图（数据提示"冷藏 12 条，一年后可能忘光"，中性文案）。
- 投影原则保证：分类/状态永远无法污染 SRS 数据（架构铁律）。

## 七、数据结构

```sql
collections(id, name, parent_id, owner_id, is_system, created_at)   -- 库/子集（原"馆/系列"）
item_collection(item_id, collection_id, is_primary)                 -- 多对多，主库标记
items(id, card_id, source, media_path, original_url, note, lang, status, created_at)  -- 状态=投影缓存
item_tags(item_id, tag)                                            -- 冗余标签（搜索增强）
```

- 与《拾忆App架构设计》数据模型一致（删除了游戏版 furniture/palace 字段）。
- 离线优先：全本地；同步走云盘快照/日志（存储方案不变）。

## 八、冷启动与验证指标

### 冷启动

```
首次进入（0 收藏）：预置 3 个系统库「工作」「日语」「灵感」
  + 引导"从剪贴板/相机收第一件"（收藏第一件即完成引导）
  → 第一周收藏 ≥3 条 → 解锁月度报告入口（给一个即时的"成长感"）
```

### 验证指标

| 指标 | 达标线 |
| --- | --- |
| 自动打标准确率（用户不改动） | > 80% |
| 用户主动改库率 | < 30% |
| 按库复习使用率 | > 40% |
| 待归类 14 天滞留（落入未分类） | < 30% |
| 一周后仍有自定义库/改名 | > 40% |

> **一句话**：分类在拾忆里没有"整理"的面孔，只有"复习筛选 + 统计 + 薄弱加权"三副数据面孔——好分类的唯一标准，是用户复习时能一秒找到"常去的那几个库"。
