## 一、引擎的通用性：六项能力抽象

记忆教练的核心不是"单词"也不是"三 Tab"，而是六项可复用的能力：

| 能力 | 载体 | 对任意知识是否成立 |
| --- | --- | --- |
| 间隔重复调度 | SRS 引擎（SM-2→FSRS，纯函数） | ✅ 一切记忆都适用 |
| 主动回忆交互 | 闪卡先猜后看 / 打字默写 | ✅ 一切提取都适用 |
| 情境召回 | 按库/主题分组复习（Method of Loci 的工具形态） | ✅ 一切有结构的知识 |
| 多模态编码 | 图 / 发音 / 例句 / 剪藏原文 | ✅ 按品类换素材 |
| 交错与混排 | 全库混合队列 + 薄弱加权 | ✅ 一切要"去顺序依赖"的知识 |
| 收藏管道 | 分享 / 剪贴板 / OCR / 手录 | ✅ 与内容无关（任何内容都能划进来） |

> **推论**：记忆教练是"怎么记住"的运营层，"记什么"是内容层——两者解耦，扩展 = 推进内容的词库/模板 + 一套领域提示语，架构几乎不动。

## 二、品类扩展地图

### 2.1 语言矩阵（横向复制成本最低）

| 语言 | 与日语用户重叠 | 痛点强度 | 确定性 | 优先级 |
| --- | --- | --- | --- | --- |
| 英语 | 高（已计划 V1.x） | 高 | 已验证（墨墨/不背） | **P0 并行** |
| 韩语 | 极高（兴趣人群重合） | 高（谚文初学退坑率高） | 中 | P0.5 第二波 |
| 中文学习（对外/启蒙） | 低（但痛点最强） | **极高（汉字为最难记忆符号）** | 中 | P1 差异化大招 |
| 法语/德语/西语 | 中 | 中 | 中 | P2 |
| 小众语言（泰/越/阿） | 低 | 高（资料稀缺=机会） | 低 | P3 |

### 2.2 知识矩阵（非语言，引擎直接套用）

| 赛道 | 内容示例 | 付费意愿 | 人群规模 | 备注 |
| --- | --- | --- | --- | --- |
| 医学/医护 | 解剖术语、药理、缩写 | **高**（挂科焦虑） | 大（Anki 医学生封神） | "效率工具"话术零教育成本 |
| 资格考试 | 法考、财会、教资 | 高 | 大 | 以"记忆集"内容包形式切入 |
| 程序员 | Git/快捷键/正则/SQL | 中高 | 中 | 技术社区口碑传播力强 |
| 银发认知 | 人名面孔、清单记忆 | 中（**子女付费**） | 增长快 | 只做"认知活跃练习"，禁医疗声称 |
| 儿童启蒙 | 识字/拼音/乘法口诀 | 中（**家长付费**） | 大 | 儿童隐私合规重，时机靠后 |
| 历史/地理 | 年代事件、国家首都 | 低-中 | 中 | 长尾，内容市场阶段再说 |
| 艺术/兴趣 | 乐理、植物名、菜谱 | 低 | 中 | 长尾 |

## 三、人群扩展地图

### 3.1 从"学语言的人"到五类新人群

| 现有画像 | 邻接扩展 | 付费决策人 | 关键差异 |
| --- | --- | --- | --- |
| 兴趣型日语新人 | → 韩流/兴趣学习者（韩语、追番） | 自己 | 内容邻接，成本最低 |
| JLPT 备考者 | → 成人考证党（医学/法财） | 自己 | **效率刚需**，付费意愿最高 |
| 职场成人学日英 | → 中老年（记性焦虑） | **子女** | 副卡模式：子女付费父母使用 |
| 成人（20-40） | → 儿童（5-12） | **家长** | 亲子共学 + 家长看板，合规重 |
| 个人学习者 | → 教师/机构（B 端） | 机构 | 班级布置复习包 |

### 3.2 人群 × 内容的正确组合（邻接矩阵）

```
              语言学习        知识记忆
青年兴趣      ★日语/韩语       ○历史地理
青年刚需      英语             ★医学/考证/编程
中年成人      英语口语          ○职业提升
中老年        —                ★认知练习（亲友付费）
儿童          ★启蒙外语         ★识字（家长付费）
```

> ★ = 优先做（用户量 + 付费意愿双高）；○ = 内容市场阶段的长尾；— = 不进入。

## 四、四大新赛道详设

### 4.1 中文学习（汉字拆分记忆）——差异化最强的一张牌

- **定位**：记忆教练的中文内容集 = HSK 分级词表 + 汉字"拆分记忆模板"（氵=河流、宀=屋顶、森=三棵树），配合部首部件关系卡片。
- **为什么是王炸**：汉字是**全球记忆痛点之王**（老外靠抄写硬记）；"拆字成画"是中文母语者自己学汉字的天然方式——记忆教练已支持的 图片+部件卡片 交互可以直接承接。
- **人群**：a) 海外中文学习者（HSK 备考人群庞大）；b) 国内 5-12 岁识字（家长付费模式，亲子看板）。
- **切入方式**：不必新建 App——以"中文学习内容包 + 汉字模板"进入记住库，复用收藏管道（拍下路牌/课本页 OCR 即成卡）。
- **优先级**：日语/英语验证后，中文内容是差异化最强、护城河最深的选择（同行几乎全是"描红"路线，没有"SRS 记忆系统"路线）。

### 4.2 医学 & 考证（付费意愿最高的效率赛道）

- **定位**：医学术语记忆集（解剖/药理/缩写）+ 考证词库包（法考/财会/教资）。
- **为什么有效**：医学与考证人群是 Anki 的头号信徒、日程最紧、"效率"话术零教育成本；Anki 兼容导入让现有牌组用户**一键迁移**。
- **玩法特点（工具版）**：术语卡多模态（标本图/缩写展开）、错题修复清单、考试冲刺模式（倒排期高权重）。
- **切入方式**：作为内容包售卖（付费验证第二曲线），不新建 App。

### 4.3 银发认知练习（子女付费的增量市场）

- **定位**：记忆教练"大字模式 + 认知练习集"：人名+面孔（SRS 记住新认识的人）、清单记忆（购物/服药清单）、旧照片配词（回忆刺激）。
- **为什么有机会**：老龄化 + 记性焦虑；**付费决策人是子女**（"给爸妈买"心理），客单价可比肩健康类订阅。
- **红线硬约束**：严禁"防痴呆/治疗"医疗声称（合规），定位只能是"认知活跃练习"。
- **切入方式**：独立皮肤包（大字 + 极简）+ 分享授权（孩子帮父母配置远程看护视图，需谨慎合规）。

### 4.4 程序员 & 专业人群（社区传播力最强的细分）

- **定位**：命令/概念记忆集——Git 命令、快捷键、正则、SQL 语法（以"记忆集模板"形式预置）。
- **为什么有效**：技术人群工具付费习惯好；Anki 兼容导入 + 键盘快捷键复习（桌面端天然适配）体验远超通用工具。
- **传播**："我用记忆工具记 Git 命令"自带技术社区话题性。

## 五、邻接扩展原则与路线图

### 5.1 三条邻接原则（防摊大饼）

1. **内容邻接优先**：新内容尽量与现有用户重叠（日语→韩语，一套收藏管道全通用）。
2. **引擎复用，模板更换**：扩展 = 新词库/记忆集 + 领域提示语 + 少量卡片模板，绝不为新赛道重写架构。
3. **一个领域一种模板**：记忆教练工具外壳统一，但每领域给专属"卡片模板"（汉字的部件卡、医学的缩写卡、银发的面孔卡）——否则就是"又一个通用闪卡"。

### 5.2 建议路线图（记忆教练时钟）

```
V0（现在）     日语 + 收藏管道（验证核心：收藏→复习闭环）
   ↓ 验证：收藏→复习转化 > 40%
V1（+3~6 月）  英语频道 + Anki 兼容（数据自由，接住 SRS 已教育人群）
   ↓
V2（+6~12 月） 中文学习内容集（差异化王牌）
             + 医学术语记忆集（第二付费曲线，验证"知识记忆"品类）
   ↓
V3（+12 月+）  银发大字包（子女付费）or 内容市场（创作者/UGC）
```

### 5.3 每个扩展的验证指标（防自嗨）

| 扩展 | 关键验证指标 | 不达标 |
| --- | --- | --- |
| 英语频道 | 新频周留存 ≥ 日语首版 80% | 砍掉，不引第二语言 |
| 中文内容集 | 海外获客 CAC < 8 美元（或国内付费问卷 > 20%） | 转儿童识字线 |
| 医学记忆集 | 7 日付费转化 > 2.5% | 停留内容包，不扩产品 |
| 银发线 | 子女付费问卷意向 > 20% | 暂缓 |

## 六、不做清单与风险

| 不做 | 原因 |
| --- | --- |
| K12 学科辅导（数理化） | 红海 + 监管重 + 与"记忆工具"定位漂移 |
| 全部主流语言同时上 | 摊大饼，无赛道做深 |
| 银发"防痴呆"声称 | 医疗合规红线，一碰就死 |
| 早早上线 UGC 内容市场 | 审核/质量/版权成本，独立开发者扛不住 |
| 儿童独立 App（初期） | 隐私合规（未成年人保护）重，先做家长陪跑模式 |

| 风险 | 对策 |
| --- | --- |
| "什么都能装" = 什么都装不深 | 邻接原则 + 每领域专属模板（5.1） |
| 新赛道内容版权（医学图/教材） | 公开教材公共领域内容 + 自产图解 |
| 工具同质化内卷 | 靠差异化王牌（汉字拆分记忆）保命 |
| 精力被多线拖垮 | 一次只开一条线，指标不达标即停 |

## 七、终局：内容市场与平台化

- **形态**：记忆教练 = 用户自带内容的"记忆集市场"（类 Quizlet 牌组市场 × 无需配置的体验）：创作者上传"记忆集"（词表 + 卡片模板 + 封面），用户一键导入；创作者分佣。
- **时机**：垂直赛道验证 2 个以上、且有稳定创作者社区后（约 V3），过早做 = 内容荒芜。
- **为什么终局是它**：SRS 引擎 + 收藏管道 + Anki 兼容的资产全在平台侧，内容边际成本趋零；而 UGC 每个"记忆集"自带创作者推广 = 增长引擎。

> **一句话总结**：记忆教练的边界不是"背词"，而是"一切值得长期记住的东西"——路径是**先日语打透收藏→复习闭环，英语+Anki 兼容接住效率人群，用中文拆分记忆打差异化王牌，用医学/考证验证知识品类**，最后用记忆集市场把它变成平台。人群跟随内容自然扩大：兴趣青年 → 考证刚需 → 亲子与银发 → 创作者生态。
